## Cronum Work

Tasks, Projects, Next and Notes in one app: one account and one sign-in, shared with whoever you
choose and reachable by your AI assistant over MCP.
[work.cronumstudio.com](https://work.cronumstudio.com)

| Module | |
| --- | --- |
| **Tasks** | Task and shopping lists. |
| **Projects** | Phases, dated tasks and deadlines, in a Gantt chart. |
| **Next** | A running log of what's done and what comes next. |
| **Notes** | Notes and notebooks, with files and version history. |

The platform the modules share lives in [suite-core](https://github.com/cronumstudio/suite-core).
