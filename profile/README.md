## Cronum Work

One app, four modules, shared with whoever you choose and reachable by your AI assistant
over MCP: [work.cronumstudio.com](https://work.cronumstudio.com).

| | |
| --- | --- |
| **Tasks** | Task and shopping lists. |
| **Notes** | Notes and notebooks, with files and version history. |
| **Projects** | Phases, dated tasks and deadlines, in a Gantt chart. |
| **Next** | A running log of what's done and what comes next. |
