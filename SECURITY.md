# Security policy

This policy covers every repository of the cronumstudio organization and the hosted
service at work.cronumstudio.com and cronumstudio.com.

## Reporting a vulnerability

Please report it privately, never in a public issue or pull request:

- on GitHub, with **Report a vulnerability** on the repository's Security tab (private
  vulnerability reporting), or
- by email to hello@cronumstudio.com, with "Security" in the subject.

Say what you found, how to reproduce it and what it lets someone do. We answer within a
few working days, keep you informed while we fix it, and credit you when it's published
if you wish.

Please don't access other people's data, degrade the service for others, or run automated
scanners against the hosted service: a test account of your own is enough to show a
problem.

## Supported versions

Only the latest release of each repository, which is what the hosted service runs.

The same contact is published at https://cronumstudio.com/.well-known/security.txt.
